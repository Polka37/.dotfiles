# My personal dotfiles
## Installation

Clone repository to your home folder
* git clone https://github.com/Polka37/.dotfiles

Create symlinks via stow
* Make sure to move old config directories somewhere else
* stow git kitty fastfetch fish sway wofi waybar mpd
